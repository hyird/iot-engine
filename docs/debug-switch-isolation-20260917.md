# 设备与链路调试独立

## 行为

- 设备报文入口和图标状态只使用设备自身 `debug_enabled`，不继承 `link_debug_enabled`。
- 关闭自身调试后收起报文窗口，取消该报文快照查询，并由关闭回调移除页面的报文订阅范围；页面本身需要的实时连接继续保留。
- EdgeNode 报文入库与本地 Collector 分别按链路、设备开关选择调试索引。只开链路不新增设备调试轮次，只开设备不新增链路调试轮次。
- 保留已记录轮次与报文历史，不修改生产开关设置。不改设备、链路调试 HTTP 地址、DTO 字段或已部署固件协议。
